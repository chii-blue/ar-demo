# 謎解きAR検証デモ（案2：家紋風マーカー）

このフォルダは、AR.js の動作確認をするための最小限のサンプルです。
まずは AR.js 標準の「Hiroマーカー」で動作確認をし、問題なく動いたら
オリジナルの「家紋風マーカー」に差し替える、という2段階で進めます。

---

## STEP1：まずは標準マーカーで動作確認

### 1. Hiroマーカー画像を用意する
以下からダウンロードして、A4用紙に印刷してください。
https://github.com/AR-js-org/AR.js/blob/master/data/images/hiro.png

### 2. ローカルサーバーを起動する
カメラを使うため、`file://` で直接開くのではなく、必ずローカルサーバー経由で開く必要があります。

Claude Code のターミナルで、このフォルダ内に移動して以下を実行してください。

```
npx serve .
```

表示されたURL（例: http://localhost:3000）にスマホからアクセスします。
（パソコンとスマホが同じWi-Fiに繋がっている必要があります。
 パソコン側のIPアドレスを調べて `http://192.168.x.x:3000` のようにアクセスしてください）

### 3. カメラ利用の許可について
スマホのブラウザは、**httpsでない場合カメラ権限を許可しないことが多い**です。
ローカル検証で動かない場合は、以下のいずれかを試してください。
- ngrok（`npx ngrok http 3000` 等）で一時的にhttps化する
- 先にGitHub Pagesで公開してhttps環境で試す（STEP3参照）

### 4. 印刷したHiroマーカーにスマホをかざす
幽霊のオブジェクトと「鏡に映る数字を数えよ」というテキストが浮かび上がれば成功です。

---

## STEP2：オリジナルの「家紋風マーカー（案2）」に差し替える

AR.jsのパターン型マーカーは、画像をそのまま認識するのではなく、
専用ツールで「.patt」という認識用データファイルに変換する必要があります。

### 1. マーカー生成ツールにアクセス
https://ar-js-org.github.io/AR.js/three.js/examples/marker-training/examples/generator.html

### 2. 案2のデザイン画像をアップロード
白黒でコントラストの強い画像（今回の家紋風デザイン）をアップロードすると、
自動で `.patt` ファイルが生成されます。
※ このツールはブラウザ上で完結するので、Claude側での生成はできません。ご自身の画像でお試しください。

### 3. 生成した .patt ファイルを配置
このフォルダ内に `markers` フォルダを作り、`kamon-pattern.patt` として保存してください。

```
ar-demo/
├── index.html
├── README.md
└── markers/
    └── kamon-pattern.patt
```

### 4. index.html を書き換える
`index.html` 内の以下の行を

```html
<a-marker preset="hiro">
```

以下のように差し替えてください。

```html
<a-marker type="pattern" url="markers/kamon-pattern.patt">
```

### 5. 印刷する画像について
マーカーとして認識させる画像自体（案2のデザイン）も、A4等で印刷して使用します。
これはSTEP2-1でアップロードした画像と同じものを使ってください。

---

## STEP3：GitHub Pagesで公開する

1. このフォルダの中身をGitHubリポジトリにアップロード
2. リポジトリの Settings → Pages で公開設定（ブランチ: main, フォルダ: / (root)）
3. 数分後、`https://ユーザー名.github.io/リポジトリ名/` でアクセス可能に
4. このURLをQRコード化すれば、参加者はカメラで読み取るだけでアクセスできます

---

## 現状の制約・注意点

- 今回のコードは「動作検証用のラフ版」です。実際のイベントで使う場合は、
  幽霊の見た目（3Dモデルや画像）をもう少し作り込む必要があります
- 照明が暗い場所（宴会場の演出等）では、マーカー認識精度が落ちる可能性があるため、
  実際の設置場所での実地テストを必ず行ってください
- 複数の謎解きポイントを作る場合は、`<a-marker>` を複数用意し、
  それぞれ別の `.patt` ファイルを割り当てる形になります
